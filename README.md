# Student Wellness & Early Intervention System

A role-based web application designed to support student
wellness through assessment, early intervention and
communication between students, counsellors, faculty and
administrators.

## User Roles

- Student
- Counsellor
- Faculty
- Administrator

## Technologies

- HTML
- CSS
- JavaScript
- Firebase Authentication
- Firebase Firestore
- Chart.js
- Git & GitHub

## Current Status

Project initialization completed.

## Modules

### Student
- Registration
- Login
- Wellness Assessment
- Wellness History
- Support Requests

### Counsellor
- Dashboard
- Case Management
- Counselling Notes
- Follow-up Management

### Faculty
- Student Referral
- Academic Concern Reporting
- Referral Tracking

### Administrator
- User Management
- System Monitoring
- Analytics
- Reports
